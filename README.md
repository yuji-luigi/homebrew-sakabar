# homebrew-sakabar

The [Homebrew](https://brew.sh) tap for the Sakabar gateway: it runs on your Mac next to Herdr and lets you follow and
drive your coding agents from a browser or the Sakabar Sessions app on your phone.

```sh
brew install yuji-luigi/sakabar/sakabar
sakabar service install   # start it now and at every login, on http://127.0.0.1:4199/
sakabar pair              # pair a browser or your phone
```

After `brew upgrade sakabar`, restart the service so it runs the new version:

```sh
launchctl kickstart -k gui/$(id -u)/dev.sakabar.daemon
```

Before `brew uninstall sakabar`, run `sakabar service uninstall`. Your data stays in `~/.sakabar-gateway`.

Without Homebrew, the installer copies the same files to `~/apps/sakabar` and installs the service:

```sh
curl -fsSLO https://github.com/yuji-luigi/homebrew-sakabar/releases/latest/download/install.sh
sh install.sh
```

The [releases](https://github.com/yuji-luigi/homebrew-sakabar/releases) here hold each version's macOS tarballs
(`sakabar` and the web dashboard), `install.sh` and `SHA256SUMS`; the formula and the installer check the tarball
against its SHA-256. An installed gateway looks here once a day for a newer release, and `sakabar update` downloads
it from here. The gateway's source is private: these files and `Formula/sakabar.rb` are generated by its release
script and pushed here, so they aren't edited in this repository.
